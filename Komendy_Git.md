# Moja ściągawka komend Git

## 1. Podstawowa praca (tego używasz ciągle)
* `git status` - Pokazuje stan plików
* `git add .` - Dodaje wszystkie zmiany (stage)
* `git commit -m "opis"` - Commit z opisem lokalnie
* `git fetch` - Sprawdza zdalne zmiany
* `git push` - Wysyła na serwer
* `git pull` - Pobiera z serwera

## 2. Tworzenie i pobieranie
* `git init` - Inicjuje nowe repozytorium
* `git clone <link>` - Kopiuje zdalne repozytorium

## 3. Gałęzie (Branches) i łączenie
* `git branch` - Pokazuje listę gałęzi
* `git checkout <nazwa>` - Zmienia aktywną gałąź
* `git merge <nazwa>` - Łączy dwie gałęzie

## 4. Historia i cofanie zmian
* `git log` - Wyświetla historię zmian
* `git rm --cached <plik>` - Przestaje śledzić plik
* `git restore <plik>` - Cofa lokalne zmiany
